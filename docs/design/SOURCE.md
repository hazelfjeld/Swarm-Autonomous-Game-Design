The workbook and original Fish World reference images are not bundled with this intake. The GDD contains the complete proposed rules for this intake. Section 19 explicitly records material changes from the workbook; do not silently recover conflicting old values from a separate workbook. Preserve stable content identifiers. If an implementation task needs a missing asset/reference or an unresolved workbook-only detail, record that specific dependency rather than inventing its contents.

[DESIGN_BASELINE.md](DESIGN_BASELINE.md) is an intake summary and [FIRST_SLICE.md](FIRST_SLICE.md) scopes the first work. Neither replaces the source. The latest user instruction and accepted decisions govern any later change; record versioned changes and their consequences in the decision log. Initial arithmetic/model checks described in the GDD do not establish implemented behavior or human enjoyment.
