# Little Ray design source record

## Current governing version

**Little Ray Game Design Document v2.0**, dated 23 November 2026, is the current received working design. [DIRECTOR-002 #22](https://github.com/hazelfjeld/Swarm-Autonomous-Game-Design/issues/22) records Hazel's explicit correction requesting a Dragon City / Monster Legends-style clone with cute manta rays after rejecting the prior sanctuary interpretation.

The complete [GDD.md](GDD.md) is canonical readable text. The [Word companion](source/Little_Ray_GDD_v2.0.docx) contains the same 20 chapters with the concept cover, linked contents and formatted tables. It is 34 pages with 20 tables. All 1,052 authored text units and all nine external hyperlink targets were checked in the generated Word document. Every rendered page was visually inspected; the final island clarification changed only page six, which was re-inspected.

Status is **received**, not blanket approval or human playtest evidence. The clone-like direction is an explicit user requirement; the detailed numbers, roster and staged implementation are authored proposals. The revised document's section 20 records official reference sources, the pinned Game Designer skill and historical project provenance. The prior concept illustration remains a concept, not a shipped screenshot or runtime sprite.

## Revision and evidence rules

GDD v2 section 19 explicitly supersedes the conflicting economy, housing, nursery, rarity, progression and combat rules. Preserve stable species/individual identifiers and compatible runtime/capability work. Earlier intake reviews establish preservation of v1, not acceptance of v2 mechanics. The current revision has its own [validation record](V2_VALIDATION.md) and exact-head review/integration evidence.

Future user decisions and accepted revisions should update the source pointer, summaries and affected task criteria together while retaining history. Actual game behavior, human comprehension, pacing and online fairness still require their own evidence. No public deployment, schedule change or game implementation is performed by this document revision.
