# Little Rays: Tidepool Palette 01

Four owner-selected static concept cutouts: Jade Current, Strawberry Milk, Moon Quilt and Tangerine Sherbet. These are candidate assets for visual reference and prototyping, not the formal Blueberry comparison, an animated roster or approved runtime sprites.

- All four are 736 × 388 RGBA PNGs with consistent scale and transparent padding. No game manifest or import settings are changed.
- Provenance: original ImageGen lineup approved by the project owner on November 25, 2026; colors come from that approved lineup, with a separately generated alpha matte. The supplied inspiration image and source contact sheet are not included.
- Validation: each PNG opens as RGBA, has fully transparent borders and one connected silhouette at the alpha midpoint. Opaque RGB pixels match the approved source exactly. Cutouts inspected against light and dark backgrounds.
- Not verified: Godot import, play-scale readability, animation, pivots, hitboxes or build integration. No production asset is replaced. This intake does not advance ART-002 or unlock ART-003.
